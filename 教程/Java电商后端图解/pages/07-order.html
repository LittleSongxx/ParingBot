07 · 下单五阶段

全站最硬的一段代码。一个方法被切成五段，每段只解决一个矛盾——把「长事务」切成「短事务 + 可补偿的远程写」。没有 Seata，靠结构换一致。

⚠️ 先看一个反直觉 postOrder 故意不标 @Transactional。注释里记着事故：早期版本把远程调用包进事务，一次远程调用占连接 18.1s，把连接池抽干。五阶段的切法就是从这次事故里长出来的。OrderInfoServiceImpl.java:183
