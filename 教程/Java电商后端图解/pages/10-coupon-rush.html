三个 Lua 为什么长这样

  • reserve：三键联动（计数、SET、hash）必须一次原子改，拆开就是超卖或重复；SET 成员配 hash TTL，hash 过期的懒清理顺带 srem，否则用户永远「已参与」。
  • rollback 用 incr（相信 Redis 当前值，退回预占时多扣的 1）；release_align 用 set（不相信 Redis，直接改成 DB 余量）——两个「还库存」语义完全不同。
  • sweep：参与者 SET 无 TTL，靠定时任务按「hash 还在不在」摘僵尸成员。
