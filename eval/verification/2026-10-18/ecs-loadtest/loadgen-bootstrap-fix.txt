# loadgen bootstrap 失败排查

旧 loadgen 在每个 VU 的 bootstrap 中调用 /internal/demo/seed（100 用户 + 20 商品写事务）；
160/240 VU 时 4 个进程并发大量 seed，session 响应 data 为 null，loadgen 报
"'NoneType' object is not subscriptable"（4–8 个 VU bootstrap 失败）。

修复：
  1. worker 在启动 VU 前只 seed 一次；
  2. OrderSession.bootstrap 对 success/data 做显式校验；
  3. demo seed 仍在 mock 模式且密码有效时运行。

验证：库存重置到每 SKU 500 后，160 VU/30s 复测 0 个 bootstrap 失败、0 业务错误。
原始 JSON：ecs-order-seedfix-160.json。
