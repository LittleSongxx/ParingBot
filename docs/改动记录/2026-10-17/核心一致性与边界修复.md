# 核心一致性与边界修复

## 需求

在 README/ADR 收敛的同时，修掉会影响交易正确性或安全边界的已知问题，并为每个修复补回归测试。范围限定 Java 后端，不引入分布式事务/分库分表。

## 变更

1. **搜索零命中**：`ProductController#loadProduct` 在 ES 返回空 ID 列表时直接返回空分页（总数 0），不再回 DB 查全量；避免“搜不到反而看到所有商品”。
2. **索引全量重建**：`ProductIndexService#rebuildAll` 改为 keyset 翻页（新增 `ProductInfoMapper#selectForIndex(lastId, limit)`），不再受 `PageUtils` 100/500 上限截断；250 条数据 3 批完成。
3. **公开商品详情**：`ProductInfoService#getProduct4VOByProductId(productId, requireOnSale)`；公开入口拒绝非 `ON_SALE`，管理端预览可看下架；缓存命中与 DB 回源两条路径都校验；上下架/删除提交后失效商品缓存。
4. **券模板状态**：`CouponInternalService` 在锁券/预览前拒绝 `STOP/OVERDUE`；`FINISH` 仍允许已发券使用；`coupon_scope` 未校验保留为已知边界。
5. **限流键**：`RateLimitAspect` 的 key 加入 `Controller#method#参数个数`，不同接口不再共享桶；空 userId 直接 901。
6. **网关白名单**：`/api/product/**` 收窄为 `loadCategory`、`loadCommendProduct`、`loadProduct`、`getProduct` 四个精确读路径；未登录写路径 401。
7. **购物车 SKU**：非空 `propertyValueIds` 必须命中真实 SKU，否则报“规格组合不存在”；空值才使用默认 SKU；下架/零库存仍允许加入，由结算拦截。
