## 未完成项 / 接受风险（如实记录）

1. **`/internal/**` 共享令牌**：改成 per-service 令牌或签名 actor 属结构性改动（要动全部服务与
   助手调用约定），当前无已知利用链 → 明确列为接受风险并写进 README。
2. **检索修复的 HTTP 层端到端确认**：本轮以"原失败模式单测 + 真 ES `run_sync` 查询"为准；
   经网关+助手认证的 `searchProbe` 在本地会话里未走通（助手侧 merchant 内省与本地 cookie 组合），
   部署后建议核对一次检索回执元数据里的 `lexical_backend=es_bm25`。
3. **券管理页**：读接口要求 `coupon:manage`（展厅没有），前端菜单已去掉该入口；若希望展厅可看券，
   需要拆分读/写权限点（属权限模型调整，未做）。
4. **资源 id 非 CSPRNG**：保留（不影响不可猜性），仅安全码已切 SecureRandom。
5. 同期既有未完成项不变（见同日 P0+P1 记录：幂等账本自动闭环、keyset 分页、DLedger、从机兜底、Sentinel 演练等）。
